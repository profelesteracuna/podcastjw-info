De informes escritos a audio, de forma automatizada.

PodcastJW convierte informes almacenados en Google Drive en archivos MP3 para escucharlos de manera privada.

¿Qué hace PodcastJW?

Una automatización identifica un informe diario en una carpeta específica de Google Drive, prepara su texto, genera la narración mediante el motor de voz Piper y almacena el audio resultante en otra carpeta privada de la misma cuenta.

ENTRADA

Google Drive

Lectura de informes seleccionados por el propietario.

RESULTADO

Audio MP3

Archivos de audio guardados en una carpeta privada.

PROCESAMIENTO

GitHub Actions + Piper

Automatización y síntesis de voz local al entorno de ejecución.

ACCESO

Uso personal

No existe registro público ni acceso para usuarios externos.

¿Por qué solicita acceso a Google Drive?

El propietario autoriza una conexión OAuth para que rclone pueda obtener el informe diario y guardar el archivo de audio. El permiso técnico de Drive puede ser más amplio que las carpetas utilizadas: la automatización se ha configurado para trabajar únicamente con las carpetas propias de este proyecto.

Las credenciales permanecen fuera de este sitio. El contenido se procesa temporalmente durante la ejecución automatizada; no se presenta públicamente aquí.

Privacidad: consulte la política de privacidad para conocer cómo se procesan los datos y cómo revocar el acceso.
