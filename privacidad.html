Política de privacidad

Cómo PodcastJW utiliza Google Drive para producir archivos de audio privados.

Última actualización: 10 de noviembre de 2026.

1. Responsable y finalidad

PodcastJW es una herramienta de uso personal, administrada por su propietario, para convertir informes de texto seleccionados en Google Drive en archivos de audio MP3.

2. Datos de Google a los que se accede

Cuando el propietario concede acceso mediante Google OAuth, rclone puede acceder a Google Drive dentro del alcance autorizado. El permiso puede permitir el acceso amplio a archivos de Drive, aunque la automatización está configurada para utilizar únicamente las carpetas de informes de origen y audios de destino del proyecto.

Los datos procesados incluyen textos de los documentos seleccionados, nombres de archivos y metadatos necesarios para localizar informes y evitar duplicados.

3. Procesamiento

  • Los documentos se descargan temporalmente desde Google Drive durante una ejecución de GitHub Actions.
  • Piper realiza la síntesis de voz en el entorno de ejecución. No se envía el texto a un servicio de texto a voz de pago.
  • Los MP3 se suben a una carpeta privada de Google Drive.
  • Los archivos temporales desaparecen al eliminarse el entorno de ejecución; GitHub puede conservar registros técnicos de las tareas según su funcionamiento y configuración.

4. Almacenamiento y seguridad

Los informes y audios persistentes permanecen en Google Drive del propietario. Las credenciales OAuth se almacenan en la configuración local de rclone y, para la automatización, en un secreto cifrado de GitHub Actions. Estas páginas públicas no contienen credenciales ni documentos privados.

5. Cesión y uso limitado

Los datos no se venden ni se utilizan con fines publicitarios, de perfilamiento o de marketing. Para operar técnicamente intervienen Google Drive y GitHub Actions. Los documentos de origen no se publican en estas páginas.

La utilización de información recibida mediante las API de Google se limita a las funciones descritas y respeta los requisitos aplicables de uso limitado de datos de Google.

6. Revocación del acceso y eliminación

El propietario puede revocar el acceso desde las conexiones de su cuenta de Google, eliminar informes y audios en Drive o retirar el secreto de GitHub para impedir nuevas ejecuciones autorizadas.

7. Visitas a este sitio

Este sitio informativo es estático: no incorpora formularios, analítica propia ni cookies configuradas por PodcastJW. El proveedor de alojamiento puede gestionar datos técnicos de las conexiones de acuerdo con sus propias políticas.

8. Contacto y cambios

Para consultar sobre el tratamiento de datos, puede utilizarse el correo de asistencia indicado en la pantalla de consentimiento OAuth de Google. Esta política se actualizará si cambian las funciones o las prácticas de tratamiento.
